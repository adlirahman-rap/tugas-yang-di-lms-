# 🐍 Python Dasar - Portofolio Praktikum Santrikoding

Repositori ini berisi kumpulan kode sumber dan dokumentasi praktikum dari seri tutorial **"Santrikoding - Python Dasar"**. Proyek ini dibuat untuk mempelajari dasar-dasar pemrograman Python dari tingkat pemula hingga konsep Pemrograman Berorientasi Objek (OOP) serta pengelolaan modul dan *package*.

## 📂 Struktur Proyek & Daftar Materi

Berikut adalah daftar materi yang telah diimplementasikan:

- **#1**: Pengenalan & Instalasi Python
- **#2**: Struktur Dasar Program Python
- **#3**: Tipe Data Dasar
- **#4**: Variable
- **#5**: Konstanta
- **#6**: Operator
- **#7**: Control Flow (`07_control_flow.py`)
- **#8**: Function (`08_function.py`)
- **#9**: List, Tuple, dan Set (`09_koleksi_data.py`)
- **#10**: Dictionary (`10_dictionary.py`)
- **#11**: Class & Object / OOP Dasar (`11_oop_dasar.py`)
- **#12**: Encapsulation (`12_encapsulation.py`)
- **#13**: Inheritance (`13_inheritance.py`)
- **#14**: Polymorphism (`14_polymorphism.py`)
- **#15**: Abstraction (`15_abstraction.py`)
- **#16**: Exception Handling (`16_exception_handling.py`)
- **#17**: File Handling (`17_file_handling.py`)
- **#18**: Module (`18_module_main.py` & `matematika.py`)
- **#19**: Package (`19_package_main.py` & folder `my_package/`)
